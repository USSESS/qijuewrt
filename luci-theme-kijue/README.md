# KiJueWrt Theme - OpenWrt 完整多页面主题

一套为 OpenWrt / ImmortalWrt 打造的现代卡片风主题，包含首页/网络/设备/应用/系统/终端六大页面，应用卡片根据已安装软件自动出现，背景可自定义。

## 特性

- **6 大页面**：首页（3D 路由器+实时数据）、网络、设备、应用、系统、终端
- **动态应用**：预设 28 种常见软件检测 + 自动扫描 LuCI 菜单，新装插件自动出现（带 NEW 角标）
- **实时数据**：CPU/内存/在线设备/活动连接/上下行速率，5 秒刷新
- **自定义背景**：浅色渐变 / 深色模式 / 自定义图片 / 纯色，主题色、卡片透明度可调
- **立体感设计**：多层阴影、内发光、顶部高光线、hover 上浮效果
- **自动中文**：首次启动自动设置 zh_cn
- **隐藏未安装**：未安装的软件卡片不显示，点进去不会 404

## 云编译使用方法

1. 把整个 `luci-theme-kijue` 文件夹放到你的 GitHub 仓库根目录
2. 在 `diy-part1.sh` 里添加：
   ```bash
   mv "$GITHUB_WORKSPACE/luci-theme-kijue" package/
   ```
3. 在 `.config` 里添加：
   ```
   CONFIG_PACKAGE_luci-theme-kijue=y
   ```
4. 编译完成后刷入固件，首次启动自动设为默认主题

## 主题设置

登录后台 → 系统 → KiJue 主题设置

## 兼容性

- OpenWrt 21.02 / 22.03 / 23.05 / 24.10 / 25.x
- ImmortalWrt 全版本
- x86_64 / ARM / MIPS 全架构
